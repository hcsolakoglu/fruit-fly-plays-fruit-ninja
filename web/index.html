The wiring has a job.

The neural controller only gets the game's visible RGB image and its own blade position. A simple color encoder stimulates visual projection neurons. Six rate-propagation steps carry activity through measured synapses. A fitted readout receives only descending-neuron activity.

Cut the connections or blind the input using the selector. These interventions change the actual controller. The two baseline modes are labeled explicitly.

What this experiment is.

RealMaleCNS neuron identities, synaptic counts, predicted transmitters, and soma positions.
